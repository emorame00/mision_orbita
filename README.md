# Misión Órbita

Primer avance del proyecto de Principios de Programación 1.

Estudiante: Eddie Steven Mora Mesén
Sección: SCV6

## Descripción

El proyecto incluye cuatro ejercicios en Python:

1. Calcular los recursos necesarios para una misión espacial.
2. Revisar el combustible disponible.
3. Comprobar el oxígeno y las provisiones de la tripulación.
4. Determinar si se autoriza el lanzamiento.
